# ポケカ エクストラ 対戦卓

ポケモンカードゲームの **エクストラレギュレーション** を、離れた相手とブラウザで遊ぶための盤面アプリです。

**ルールは人間が守ります。アプリは盤面を合わせ、間違いに気づけるようにするだけです。**
ルール違反を見つけても操作は止めません（警告を出して相手にも見せ、そのまま通します）。
エクストラには「その禁止を破ることで成立する」カードが実在するためです。

---

## 使う前に — カードデータを読み込む

**このリポジトリにカードデータは入っていません。** カードのテキストを配布しないためです。

初回だけ、自分の端末で読み込んでください。

1. アプリを開き、`カードデータ` の画面（`#cards`）へ
2. カードを書いた JSON ファイルを選ぶ
3. 読み込んだものはブラウザに残るので、次回からは何もしなくて構いません

> **対戦する2人が同じデータを読み込んでいる必要があります。**
> オンライン対戦でもカード定義は送り合いません（送れば配布になるため）。
> 片方だけが持っているカードは、相手の画面では正しく表示されません。

## 遊び方

### オンライン対戦（離れた相手と）

アカウントが要ります。席を他人に取られないようにするためで、身元の確認はこれだけが頼りです。

1. `アカウント` からログイン（メール／Google）
2. ロビーで接続先を **オンライン** にする
3. 片方が **部屋を作る** → 出た**部屋コード**を相手に伝える
4. もう片方がコードを入れて **参加する**

**部屋を作った側のブラウザが卓を持ちます。** その画面を閉じると対戦は終わります。
（作った側は再読み込みでも戻れません。参加した側は、同じコードで入り直せば続きから戻れます。）

### 同じネットワークで対戦

手元でサーバーを動かす方式です。開発と、同じ場所にいるときに使います。

```bash
pnpm dev:server   # ws://0.0.0.0:8787
pnpm dev          # http://localhost:5173
```

## 開発

```bash
pnpm install
pnpm start        # サーバーとクライアントを同時に
pnpm test         # 全パッケージのテスト
pnpm typecheck
```

- `packages/shared` … ルール・状態・効果の解釈。ここに全部の判断が集まっている
- `packages/server` … 対戦卓（`Room`）と WebSocket。★`Room` は `node:` に依存しないのでブラウザでも動く
- `packages/client` … 画面（React + Vite）

テストは **手元で通してから push** してください。CI ではビルドだけを行います
（サーバー側のテストはカードデータを読むので、データの無い環境では必ず落ちます）。

### 環境変数

`packages/client/.env.local` に Firebase のウェブ設定を書きます（雛形は `.env.example`）。
設定が無くてもアプリは動きます — アカウントとオンライン対戦だけが使えません。

### 公開

`main` に push すると GitHub Actions が GitHub Pages へ配信します（`.github/workflows/pages.yml`）。

配信の前に一度だけ必要な設定:

- リポジトリの **Settings → Pages → Source** を `GitHub Actions` に
- リポジトリの **Settings → Secrets → Actions** に `VITE_FIREBASE_*` を6つ登録
- Firebase コンソールの **Authentication → Settings → 承認済みドメイン** に
  `<ユーザー名>.github.io` を追加（これが無いとログインが弾かれます）

Firestore のセキュリティルールは `firestore.rules` にあります。変更したら反映してください。

```bash
npx firebase-tools deploy --only firestore:rules
```

## 作りの要点

- **卓が唯一の正しさ**（サーバー権威型）。画面は自分で状態を進めず、届いた盤面をそのまま映します
- **乱数は卓だけが持ちます**。シャッフル・コインは結果をログに残すので、ログから同じ盤面を再現できます
- **見えてよい情報だけを配ります**。相手の手札や山札の中身は、そもそも画面に届きません
- **オンラインでも卓はブラウザの中**。中継（Firestore）は、人ごとに分けた盤面と操作の要求を運ぶだけです

## 扱わないもの

カード画像・公式のロゴ・書体・エネルギー記号の画像・フレーバーテキストは扱いません。
エネルギーは自作の色付きの丸で表します。
